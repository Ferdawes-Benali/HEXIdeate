# 7arbouche

A cross-platform mobile healthcare application that helps users manage their medication schedules through intelligent reminders, voice assistance, medication adherence monitoring, and drug interaction analysis.

Available on **iOS** and **Android**, 7arbouche is designed to improve medication adherence while providing caregivers with real-time visibility into missed doses and potential medication risks.

## Features

### 📱 Cross-Platform Mobile Application

* Native mobile experience for iOS and Android.
* Easy medication schedule management.
* User-friendly interface designed for daily healthcare routines.

### 🎙️ Voice Assistant Integration

* Voice-based medication reminders.
* Hands-free interaction for improved accessibility.
* Personalized medication guidance and notifications.

### 📷 Medication Adherence Monitoring

* Uses computer vision to monitor and verify medication intake events.
* Tracks adherence history and scheduled doses.
* Detects missed medication events in real time.

### 💊 Drug Interaction Detection

* Analyzes prescribed medications for potential drug interactions.
* Warns users when combinations of medications may produce harmful reactions.
* Provides an additional safety layer before medication intake.

### 🔔 Smart Reminder System

* Sends automated reminders when medications are due.
* Escalates notifications when doses are missed.
* Helps users maintain consistent treatment routines.

### 👨‍⚕️ Caregiver Alert System

* Automatically notifies caregivers when critical medication events are missed.
* Supports proactive intervention and patient monitoring.
* Enables remote follow-up for at-risk patients.

### 🤖 Intelligent Workflow Automation

* Coordinates medication schedules, reminders, adherence monitoring, and caregiver notifications.
* Demonstrates end-to-end agent-style task orchestration across multiple healthcare workflows.

## How It Works

1. Users register their medications and schedules.
2. The application continuously monitors upcoming medication events.
3. Voice reminders notify users when medication is due.
4. Computer vision verifies medication intake.
5. Drug interaction checks analyze medication compatibility.
6. Missed doses trigger automated reminder workflows.
7. Caregivers receive alerts when intervention may be required.
